# DevKit

Muchas herramientas que solemos necesitar los desarrolladores en un único sitio.

## Self Hosting

Adelante, ponlo en tu propio dominio/subdominio para tu uso privado.

Muchas herramientas también funcionan online si lo pones en una carpeta.

## Public versión

Hay una versión pública con las herramientas que no consumen CPU del servidor (no necesitan PHP o similares) para quienes no quieran o no puedan hospedar un clon del Toolkit.

## Porqué

Yo utilizaba muchas herramientas online de buena calidad que hacían mi vida más fácil pero con el tiempo se estaban haciendo incómodas.

· Cada una un estilo
· Aceptar cookies
· Soportar la publicidad

Así que he decidio hacer mi propio Toolkit. *Libre de publicidad y libre de cookies.*
